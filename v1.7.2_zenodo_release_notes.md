**v1.7.2 — sugar beet added (patch)**

Completes the eight-crop family. Adds **sugar beet** (DWD Plant ID 253,
*Beta vulgaris*, German "Zucker-Ruebe") to the crop specification, with
modelled phases 10 (sowing), 12 (emergence), 13 (canopy closure), 24
(harvest). The crop is anchored to AGROVOC `sugar beet` (`c_7499`),
maintainer-verified against agrovoc.fao.org and confirmed at build time by
`verify_agrovoc_uris()`.

No API or behavioural change — the workflow already processed any crop present
in `.CROP_SPECS`; this adds the missing table entry and its vocabulary anchor.

The family now covers all eight target crops: winter wheat (202), winter rye
(203), winter barley (204), winter rapeseed (205), spring barley (207), oats
(208), maize (215), sugar beet (253).

The PhenoPhaseR v1.7.2 source archive is on GitHub at the `v1.7.2` tag.
